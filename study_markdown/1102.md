1102 - Vue 문법
====

ref는 원시 타입 값을 반응형으로 만드는 기능
- ref는 template 안에선 직접 가져올 순 있지만 script 안에선 value 로 접근해야 함.
```js
<script>
const bgColor = ref('');

bgColor.value = 'bg-red';
</script>

<template>
  <div @click="count++" class="btn-cnt" :class="bgColor">Count is {{ count }}</div>
</template>
```
<br>

반응성 있는 속성은 속성 앞에 : 붙이면 됨.
```html
<div @click="count++" class="btn-cnt" :class="bgColor">Count is {{ count }}</div>
```
<br>

v-model : 양방향 데이터 전송
html에서 js로, js에서 html로 value를 전송함.
원래는 js -> html 밖에 안 됨
```html
<input type="text" name="email" id="email" v-model="email">
```

v-if, v-else-if, v-else : 반응형 if 문
```html
  <p v-if="num % 2 == 0">짝수 입니다.</p>
  <p v-else>홀수 입니다.</p>
```

v-show : v-if는 노드 자체를 없애지만 v-show는 display:none 으로 안 보이게 함

v-for
- key는 고유 값
```html
  <div class="container">
    <div v-for="item in items" :key="item.id" class="card">
      <p>{{ item.kinds }}</p>
      <p>{{ item.food }}</p>
    </div>
  </div>
```

바인딩 방식 중 하나로 아래 코드 대신에
```js
const toggleBgColor = () => {
  if (bgColor.value === '') {
    bgColor.value = 'bg-red';
  } else {
    bgColor.value = '';
  }
}
```

이 코드로 변경할 수 있음
btn-toggle은 옆에 조건에 따라 적용되는 클래스
@click과 연관시키면 될 듯

```html
<button :class="{ 'btn-toggle': flg === false }" @click="flg = !flg">토글</button>
```

컴포넌트 : 재사용 가능한 UI를 분할하고 다루는 문법. 유니티의 컴포넌트와 분리되는 단위가 같은듯
- 부모 컴포넌트에서 자식 컴포넌트를 import 하여 사용
- 효율을 위해 변경이 매우 잦을 것 같으면 UI로 분리

```js
<script setup>
import DataBinding from './components/DataBinding.vue';
</script>

<template>
  <h1>APP Component</h1>
  <DataBinding></DataBinding>
</template>
```
