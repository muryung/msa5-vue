**Watchers** : 어떤 값이 변하는 것을 추적하여 특정 처리를 하는 것. Observer와 비슷한 듯

```js
watch(test, (val) => {
  const pattern = /^[a-zA-Z]+$/;

  if (val === '') {
    testErrorMsg.value = '';
  } else if (pattern.test(val)) {
    testErrorMsg.value = 'O';
  } else {
    testErrorMsg.value = 'X';
  }
});
```

**Props** 
부모가 자식 컴포넌트에 **읽기 전용**으로 Script의 변수를 전달해주는 기능

자식 측에서 props를 사용해서 부모의 변수들을 불러옴
```js
const props = defineProps({
  'item': Object,
  'str': String
});
```

```html
<template>
  <h2>Child</h2>
  <p>{{ props.item.name }}</p>
</template>
```

**Slot**
부모에서 작성한 template 정보를 자식에게 전달하기 위한 기능

```html
<template>
  <h2>Slot Child</h2>
  <button type="button">
    <slot></slot>
  </button>
</template>
```

```html
<template>
  <h2>Slot Parent</h2>
  <SlotChild>부모에서 보낸 버튼</SlotChild>
  <SlotChild>전송</SlotChild>
</template>
```

**Component Event**
부모의 함수를 자식에서 실행

부모
```html
<template>
  <h2>CE Parent</h2>
  <CEChild @addCount="addCount"/>
  <p>카운트 : {{ cnt }}</p>
</template>
```

자식
```html
<template>
  <h2>CE Child</h2>
  <!-- 두 번째 인수에 addCount 함수의 매개변수를 넣을 수 있음 -->
  <button @click="$emit('addCount')">add</button>
</template>
```
