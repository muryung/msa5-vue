JavaScript 파일 하나 당 하나의 단위. 
클래스라고 생각하면 될 듯?

- import 는 다른 파일이 공개한 값을 사용
```js
import { ref } from 'vue';
```

<br>

- export 는 하나의 파일 안의 변수, 함수, 클래스를 공개
    - export default는 하나의 값을 내보내기
    ```js
    const user = {
    id: 1,
    name: '홍길동' // 문자열이므로 따옴표 추가
    }

    export default user;
    ```

    - export named는 여러 값을 내보내기
    ```js
    export const PI = 3.14159;

    export function add(a, b) {
    return a + b;
    }
    ```

    ```js
    const PI = 3.14159;

    function add(a, b) {
    return a + b;
    }

    export { PI, add };
    ```
